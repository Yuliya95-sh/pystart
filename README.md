# Easy Python — интерактивный курс Python для ЕНТ

Сайт работает полностью в браузере (без сервера): Python 3 запускается через **Pyodide** (WebAssembly), редактор — **CodeMirror 5**, прогресс хранится в `localStorage`.

## 1. Архитектура

```
pystart/
├── index.html        — каркас страницы: шапка, сайдбар, контейнер #app, подключение CDN
├── style.css         — дизайн-токены (светлая/тёмная тема), раскладка, компоненты
├── app.js            — движок: роутер, Pyodide-воркер, редактор, автопроверка, тесты, прогресс
├── courses_data.js   — ВЕСЬ контент курса (модули, уроки, задачи, тесты) — правится без app.js
└── README.md         — эта инструкция
```

Как устроен `app.js` (разделы помечены в коде):

| Раздел | Что делает |
|---|---|
| Store | Прогресс в `localStorage` (ключ `pystart.progress.v1`): изученные уроки, решённые задачи, код задач, результаты тестов |
| Py | Pyodide в **Web Worker**. Таймаут: зависшая программа (бесконечный цикл) убивается, воркер перезапускается. Если воркер недоступен — запуск в основном потоке |
| PY_RUNNER | Python-обёртка: свой `input()` читает из поля «Ввод», перехват `stdout`/`stderr`, понятный traceback + подсказка по типу ошибки на русском |
| gradeTask | Автопроверка: прогоняет код на каждом тесте, сравнивает вывод (без учёта пробелов в конце строк) или выполняет `assert` |
| Quiz | 4 типа вопросов, подсчёт баллов как в ЕНТ (1 балл / 2 балла с частичным зачётом), разбор ошибок |
| Views | Главная, Теория, Практика, Тест, Песочница, «Модуль в разработке» |
| Router | Хеш-адреса: `#/`, `#/sandbox`, `#/m/m1/theory/0`, `#/m/m1/tasks/2`, `#/m/m1/quiz` |

## 2. Запуск

**Локально:** откройте `index.html` двойным кликом (нужен интернет для CDN). Надёжнее запустить мини-сервер в папке проекта:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000.

**GitHub Pages:** загрузите 4 файла в репозиторий → Settings → Pages → Branch `main` / root. Готово.

Первая загрузка Python занимает 5–15 секунд (около 10 МБ), дальше браузер берёт его из кэша. Статус показан в шапке.

## 3. Как добавить контент в `courses_data.js`

Код Python всегда пишите внутри ``py`...` `` — обратные слеши (`\n`) сохранятся, пустые строки по краям уберутся. В HTML-текстах символ `<` пишите как `&lt;`.

### Модуль

```js
{
  id: "m4",                       // уникальный, латиницей
  icon: "🔤",
  title: "Строки и работа с текстом",
  summary: "Краткое описание для карточки",
  // status: "soon",              // раскомментируйте, чтобы показать «в разработке»
  // plan: ["тема 1", "тема 2"],  // список тем для заглушки «soon»
  lessons: [ /* уроки */ ],
  tasks:   [ /* задачи */ ],
  quiz:    [ /* вопросы */ ],
}
```

Чтобы открыть заготовленные модули 4–7: заполните `lessons`, `tasks`, `quiz` и удалите строку `status: "soon"`.

### Урок (блоки идут сверху вниз)

```js
{
  id: "l1",
  title: "Срезы строк",
  blocks: [
    { t: "html", html: `<p>Текст урока, <code>код</code>, таблицы…</p>` },
    { t: "code", code: py`
s = "Python"
print(s[::-1])` },                                   // кнопки «Выполнить» и «В песочницу»
    { t: "code", input: "5\n7", code: py`print(int(input()) + int(input()))` },  // с вводом
    { t: "code", run: false, code: py`# только показать` },
    { t: "note", kind: "ent", title: "Типичный вопрос ЕНТ", html: `<p>…</p>` },  // kind: "" | "warn" | "ent"
  ],
}
```

### Задача с автотестами

```js
{
  id: "t1",
  title: "Палиндром",
  level: "Лёгкая",                // "Лёгкая" | "Средняя" | "Сложная"
  statement: `<p>Условие задачи (HTML)</p>`,
  starter: py`s = input()`,       // стартовый код в редакторе
  hint: `<p>Подсказка (необязательно)</p>`,
  solution: py`
s = input()
print("YES" if s == s[::-1] else "NO")`,  // эталон: показывается после решения или 3 неудачных попыток
  tests: [
    { input: "шалаш", output: "YES" },                 // открытый тест — виден как пример
    { input: "python", output: "NO", hidden: true },   // скрытый тест
    // Для функций можно проверять через assert (выполняется после кода ученика):
    // { assert: "assert is_pal('abba') == True" },
  ],
}
```

Для задач «напишите функцию» удобнее помощник `chk(выражение, ожидаемое, скрытый)` — он вызывает функцию ученика, а в таблице проверки показывает, что она вернула:

```js
tests: [
  chk("digit_sum(472)", "13"),                 // открытый тест
  chk("to_binary(10)", '"1010"', true),        // скрытый; строку пишем в кавычках Python
],
```

Для задач на файлы у теста есть поле `files`: перед запуском эти файлы создаются рядом с программой ученика (каждый запуск — в чистой папке). То же поле работает у примеров в уроках (`{ t: "code", files: {...}, code: ... }`):

```js
{ files: { "text.txt": "Мама мыла раму" }, output: "мама 1\nмыла 1\nраму 1" },
```

Вывод сравнивается построчно, пробелы в конце строк и пустые строки в конце игнорируются. Подсказки внутри `input("...")` при проверке не печатаются.

### Дополнительные задачи (файл `extra_tasks.js`)

Задачи для отработки лежат отдельно, в `extra_tasks.js`, в объекте `EXTRA_TASKS` по модулям (`m5: [...]`, `m7: [...]`). На сайте они показываются в разделе «Дополнительные задачи» и **обязательны**: модуль засчитывается, только когда решены все задачи — основные и дополнительные.

Формат тот же, что у обычных задач, но в тестах можно **не писать `output`** — ожидаемый вывод сайт получит сам, запустив `solution` на входных данных:

```js
{
  id: "x20", title: "Сумма кратных 5", level: "Лёгкая",
  statement: `<p>Дан список чисел. Найдите сумму элементов, кратных 5.</p>`,
  starter: py`a = list(map(int, input().split()))`,
  solution: py`
a = list(map(int, input().split()))
print(sum(x for x in a if x % 5 == 0))`,
  tests: [
    { input: "5 7 10 3" },                 // открытый тест — пример в условии
    { input: "-5 0 1", hidden: true },     // скрытый
  ],
},
```

Задачи разложены по пяти файлам: `extra_tasks.js` (списки, матрицы, графы), `extra_tasks_2.js` и `extra_tasks_4.js` (модули 1–4), `extra_tasks_3.js` (модули 5–7), `extra_tasks_5.js` (модули 6 и 8). В каждом модуле не меньше 20 дополнительных задач. Новые задачи можно дописывать в любой из этих файлов. `id` должен быть уникальным в пределах модуля.

Чтобы проверить файл, который **записала** программа ученика, добавьте тесту поле `after` — Python-код, выполняемый после программы; его вывод тоже сравнивается:

```js
{ files: { "nums.txt": "5 8 3" }, after: py`print(open("result.txt", encoding="utf-8").read().strip())` },
``` Для задач на графы есть готовые константы `GRAPH_READ` (код чтения графа) и `GR` (тестовые графы).

### Вопросы теста (4 типа)

```js
// 1. Один ответ — 1 балл
{ type: "single", q: "Что выведет программа?", code: py`print(7 // 2)`,
  options: ["3.5", "3", "4", "3.0"], answer: 1,            // индекс с 0
  explain: "Почему верно именно так" },

// 2. Несколько ответов — 2 балла (1 балл при одной ошибке)
{ type: "multiple", q: "Выберите верные…", codeOptions: true,  // codeOptions: варианты моноширинным шрифтом
  options: ["a", "b", "c", "d"], answer: [0, 2], explain: "…" },

// 3. Соответствие — 2 балла (1 балл при одной ошибке)
{ type: "matching", q: "Сопоставьте…",
  pairs: [ { left: "len('abc')", right: "3" }, { left: "'ab' * 2", right: "abab" } ],
  distractors: ["ab2"],                                       // лишние варианты (необязательно)
  explain: "…" },

// 4. Ввод ответа — 1 балл
{ type: "fill", q: "Впишите пропущенный оператор", code: py`last = n ___ 10`,
  answer: ["%"],                                              // все допустимые варианты
  ignoreCase: false,                                          // true — регистр не важен
  explain: "…" },
```

Тест считается сданным при результате от 70% (константа `QUIZ_PASS` в `app.js`).

### Проверка контента

Откройте сайт, нажмите F12 → Console и выполните:

```js
PyStart.selfTest()
```

Каждое эталонное решение будет прогнано через тесты своей задачи — так легко поймать опечатку в ожидаемом выводе.

## 4. Полезно знать

* Ввод данных: браузер не умеет «ждать» на `input()`, поэтому данные пишутся заранее в поле «Ввод (stdin)» — одна строка на каждый вызов.
* Таймауты: 6 с на запуск в песочнице, 3 с на один тест (константы `RUN_TIMEOUT`, `TEST_TIMEOUT`).
* Сбросить прогресс — ссылка внизу главной страницы.
